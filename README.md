# 202-maktab website

202-sonli umumiy o'rta ta'lim maktabi uchun zamonaviy, responsiv rasmiy sayt.

## Fayllar

- index.html — sahifa tuzilmasi va o'zbekcha kontent
- styles.css — ranglar, tipografiya va responsiv dizayn
- script.js — mobil menyu, scroll animatsiyalari, hisoblagichlar va aloqa formasi
- DEPLOY.md — GitHub Pages va boshqa static hosting uchun yo'riqnoma

## Ishga tushirish

Sayt server talab qilmaydi. index.html faylini brauzerda ochish yoki istalgan static hosting ga joylash kifoya.

## Tahrirlash

Aloqa ma'lumotlari, manzil, yangiliklar va rasmlar index.html ichida joylashgan. Rasm URL lari Unsplash dan olingan; ularni maktabning o'z fotosuratlariga almashtirish mumkin.
