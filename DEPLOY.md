# Deploy qilish

## GitHub Pages

1. Repository ichida Settings → Pages bo'limini oching.
2. Source sifatida GitHub Actions ni tanlang yoki branch sifatida main ni belgilang.
3. Root papkani tanlab Save tugmasini bosing.
4. GitHub bir necha daqiqada public URL yaratadi.

## Boshqa hosting

Bu loyiha build step talab qilmaydi. Repository fayllarini Netlify, Vercel yoki Cloudflare Pages xizmatlariga ulab, output papka sifatida root papkani tanlash kifoya.

## Muhim

Aloqa formasi hozircha frontend demo rejimida ishlaydi: yuborilganda foydalanuvchiga muvaffaqiyat xabari ko'rsatiladi. Haqiqiy murojaatlarni emailga yuborish uchun keyingi bosqichda backend yoki form service ulash kerak.
